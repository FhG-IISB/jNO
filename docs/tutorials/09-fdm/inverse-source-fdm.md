The strong-form solve differentiates through `custom_root`, so `jax.grad` flows to any parameter in
the residual — exactly like `fem.solve()`. Here we recover the unknown amplitude $s$ of a source
$s\,f_{\text{base}}$ from an observed steady field, by plain gradient descent on the data misfit.

## A differentiable, parameterized solve

The solve is still the one entry — `jno.fdm([...]).solve()` — with the parameter `s` sitting in the
residual term; `jax.grad` differentiates straight through it:

```python
def solve_scale(s):                      # differentiable jno.fdm([...]).solve() parameterized by s
    u = d.unknown(); ui = u.bind(x=x, y=y)
    return jno.fdm([-ui.d2(x) - ui.d2(y) - s * f_base, u(xb, yb) - 0.0]).solve()

observed  = jax.lax.stop_gradient(solve_scale(1.0))               # synthetic data at the true s = 1
grad_loss = jax.grad(lambda s: jnp.mean((solve_scale(s) - observed) ** 2))
s = 2.5
for _ in range(15):
    s = s - 2.0 * float(grad_loss(s))    # gradient descent through the solve
```

## What to notice

- No adjoint code: the gradient flows through the solve's implicit `custom_root`, the same mechanism
  `fem.solve()` uses.
- This is what lets `jno.fdm` compose into gradient-based inversion and into `jno.core`.
- It is a **twin experiment** — the observation is generated by the model at the true `s = 1`, so the
  minimizer is exactly the truth: from a wrong guess $s = 2.5$ the loop recovers $s = 1.0000$.
